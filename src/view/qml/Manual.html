Noteahead User Manual

Noteahead is a "simple" MIDI tracker and sequencer for Linux focusing on ease of use. It is designed for fast, keyboard-driven sequencing of external synths and drum machines, with clear handling of patch changes, automation, and CCs — no cryptic hex values required.

It also ships with a rack of internal instruments and studio-quality effects, so a whole song can be written, mixed and rendered to audio without leaving the application. See Internal Devices and Effect Racks below.

The Toolbar

The toolbar at the top of the window provides essential controls for song structure, pattern editing, and global settings.

Song Section

  • Player Controls: Play, Previous, Stop, and Loop buttons.
  • POS: The current position in the Song Play Order (0-indexed).
  • Skipped Patterns: Right-click on a position button to toggle its "skipped" state. Skipped positions are highlighted in red and will be automatically bypassed during playback. This also immediately updates the total song duration. Note that skipping can only be toggled when the song is stopped.
  • PAT: The Pattern Index assigned to the current song position. Changing this allows you to reuse patterns throughout your song.
  • LEN: The total length of the song (number of positions in the play order).
  • [+] / [-]: Insert or remove a position in the song play order.

Pattern Section

  • Pattern Name: Click the orange text to rename the active pattern.
  • PAT: The Active Pattern Index being edited. You can switch between patterns here to work on different parts of your project.
  • LEN: The length of the current pattern in lines (e.g., 64). Each pattern can have a different length.

Edit Section

  • STEP: The edit step. When you enter a note, the cursor automatically moves down by this number of lines. Set to 0 to stay on the same line.
  • VEL: The default velocity (0-127) assigned to new notes you input.
  • OCT: The base octave (0-8) for note entry.

Tempo Section

  • BPM: Beats Per Minute. Sets the overall playback speed.
  • LBP: Lines Per Beat. Defines how many tracker lines make up one musical beat (usually 4 for a standard 4/4 signature).

Editor Columns

Each Note Column consists of four data fields per line:

C-4 100 00 064

  1. Note (e.g., C-4): The musical pitch and octave. "OFF" indicates a Note Off event, which stops the playing note.
  2. Velocity (000-127): How hard the note is struck. 127 is maximum, 0 is silent.
  3. Delay (00-XX): Sub-line timing delay. This allows you to "humanize" your sequence by starting a note slightly after the line's exact beat. The maximum value depends on your Ticks Per Line setting.
  4. Pan (000-127): Stereo position sent as MIDI CC #10. 0 is hard left, 64 is center, 127 is hard right. Pan can be written on any note column, but it is a track-level setting: MIDI CC #10 applies to the whole channel, so if several columns carry a pan value on the same line, their average is what gets sent. For independently panned parts, use separate tracks or the Panner rack effect. A pan value can be placed on any line — including lines without a note — so that panning changes can be sent on every step regardless of note events.

Core Concepts

Tracks and Note Columns

Each track in Noteahead represents one instrument. That instrument is either an external MIDI instrument, addressed by a MIDI port and channel, or one of the Internal Devices hosted by Noteahead itself. A track drives exactly one of the two, so the channel you assign in Track Settings is what decides which synth, drum machine or internal device the notes on that track will play.

Both kinds of track behave the same way in the editor: the same note columns, the same velocity, delay and pan fields, and the same automation. The difference is only where the notes end up — out of a MIDI port, or into an internal device whose audio Noteahead mixes and renders itself. While you can change patches on-the-fly, the track-based approach keeps your sequence organized.

  • Track Settings: Set the MIDI port, channel, bank, patch, volume, pan, and cutoff. Assigning an internal device instead is done from the same dialog.
  • Drum track: When enabled in Track Settings, the track is excluded from pattern-wide transposition commands. This is useful for tracks triggering drum kits where transposition would change the instrument instead of the pitch.
  • Note Columns: Use the [+] and [-] buttons in the track header to manage multiple note columns per track, allowing for polyphonic sequencing or complex layered parts.
  • Velocity Scaling: Velocity is calculated as the product of track scale, column scale, and individual note velocity.

Internal Timing

Noteahead uses a high-precision internal timing strategy. The song is rendered into events just before playback, and the player thread syncs to these pre-calculated timestamps to ensure jitter-free and drift-free MIDI output.

Basic Workflow

Getting Started

  1. Choose an instrument: Click the settings icon on a track header to open Track Settings. A track plays either an external MIDI instrument or one of Noteahead's own Internal Devices, and this is where you pick which.
  2. ...over MIDI: Select the MIDI output port and channel for the external synth or drum machine you want the track to drive.
  3. ...or with a built-in device: Click Device Rack... in the same dialog to open the Device Rack, add an instrument such as Synth, Sampler or Drum Synth to a free slot, then select its internal port back in Track Settings. Nothing external is needed — Noteahead renders these itself.
  4. Edit Mode: Press ESC to enter edit mode. The cursor will change color to indicate you can now input notes.
  5. Inputting Notes: Use your PC keyboard as a virtual piano (e.g., Z is C, S is C#, X is D).
  6. Playback: Press SPACE to start or stop playback.

Main Context Menu

The main context menu can be accessed by right-clicking anywhere in the editor view. It provides a comprehensive set of tools for manipulating your sequence at different scopes.

  • Line: Insert or remove specific events (like Patch Changes), set sub-line delays, and manage line-specific automations.
  • Column: Perform Cut/Copy/Paste and transposition on the current note column. You can also Add Note OFF to quickly insert a note-off event on the first line of the column, Interpolate velocity or Interpolate pan across the entire column (pan interpolation fills every line in the range with a pan value), or manage column-wide automations. Move column to the left and Move column to the right reorder the columns of the track, wrapping around when moved past either end, and Delete current column removes the column the cursor is on. Deleting is a soft delete: the column is only hidden, so adding a column back with the + button on the track header restores the most recently deleted one along with its notes, its automations and its mixer settings. The other columns are unaffected — they keep their own automations and mixer settings no matter which column is deleted or where it is moved.
  • Track: Manage the current track (Insert/Delete), Add Note OFF to all columns in the track (first line), transpose all columns within the track, and edit track-specific automations. Move track to the left and Move track to the right reorder the tracks, wrapping around when moved past either end. Reordering only changes the layout: a track keeps its instrument, its automations and its mixer settings wherever it sits, and the order is the same in every pattern.
  • Pattern: Add Note OFF to all columns in the entire pattern (first line), transpose, or perform clipboard operations for the entire active pattern.
  • Song: Access the Device Rack... to manage internal instruments or perform song-wide transposition.
  • Delete unused patterns: Found in the Edit menu, this tool scans the play order and removes all patterns that are not assigned to any song position. This is useful for cleaning up patterns that were created during the composing process but are no longer part of the song.
  • Selection: When a range of lines/columns is selected, this menu allows you to perform actions specifically on that selection, such as adding automations or interpolating velocity.
  • Global Automation: At the bottom of the menu, you can find options to edit ALL MIDI CC or Pitch Bend automations in the project.

Effect Racks

Effect Rack

Accessed via Effects => Master effect rack..., the Effect Rack is the central hub for global audio processing. It has two tabs: Insert Effects, processed in order on the master output, and Send Effects, which all internal instruments can share via their sends.

The same rack appears in several places, and works identically everywhere:

  • Master rack: insert and send effects for the whole mix.
  • Device insert rack: the Insert FX button in the Device Rack gives every device its own chain.
  • Per-pad and per-voice racks: the small FX button on a Sampler pad or a Drum Synth voice opens an insert rack for that pad or voice alone.
  • Managing Effects: The rack displays a list of active effect slots. Click an active slot to open its dedicated parameter dialog. Each slot has its own enable switch, and the whole rack can be bypassed with the Enabled switch in the header — handy for switching effects off when rendering individual tracks.
  • Dynamic Addition: Effects can be added to any empty slot by clicking the (+) icon. This opens the Effects Gallery, where you can pick an effect type, Import Effect... from an exported settings file, or Copy Effect... to duplicate another effect in the same rack.
  • Manage Menu: Reorder a slot with Move Up, Move Down, Move to Top and Move to Bottom, or Export Settings... / Import Settings... to reuse an effect elsewhere.
  • Multiple Instances: You can add multiple independent effect instances. For example, you can have several FDN Reverbs with different acoustic settings.
  • Removal: Click the trash can icon on an active slot to remove the effect from the rack.

Available Effects

  • Equalizers: EQ 8-Band Parametric (Bell, Shelf, Cut and Notch types per band, plus Mid/Side modes), Vintage Passive EQ (EQP-1A style, with interacting low Boost/Atten shelves and a high bell), Air Band EQ (fixed parallel-summed bands added back to the dry signal) and Simple EQ (a single "Sounds Good" knob sweeping a loudness-smile curve).
  • Reverbs: Reverb (the FDN reverb described below), Endless Reverb (a large modulated ambient reverb with a Freeze switch for an infinite tail) and Early Reflections (the room a sound is in, without a tail, described below).
  • Dynamics: Compressor (with side-chain support), Multiband Compressor (three bands split by Linkwitz-Riley crossovers, described below), Auto Ducker (side-chain driven ducking or boosting), Limiter (lookahead brickwall with gain reduction metering), Clipper and Wave Designer (transient shaper, described below).
  • Saturation: Drive (Soft, Hard, Fold and Dist algorithms), Saturator, Tube Stage (valve preamp, described below), Analog Fuzz (a synth's drive knob: a fuzz stage played through the filter it overdrives, described below), Bass Grinder (split-band bass preamp distortion, described below) and Stereo Exciter (harmonic generator, described below).
  • Filters & Modulation: Auto Filter (swept filter with two LFOs and an envelope follower, described below), Phaser (swept all-pass cascade, described below), Chorus, Delay (Mono, Ping Pong and Tape modes, with BPM sync) and All-Pass Filter.
  • Stereo: Panner, Auto Panner, Stereo Enhancer (psychoacoustic EQ, described below), Stereo Widener (width per band, described below) and Dimension (builds width out of a mono source, described below).
  • Metering & Analysis: LUFS Meter (momentary, short-term and a gated integrated reading that runs as the song plays), dBTP Meter (true peak), RTA (real-time analyzer) and Stereo Field Meter (goniometer and correlation, described below). Use these as inserts to watch the signal at any point in the chain.

Auto Filter Parameters

A filter that sweeps itself, independent of whatever made the sound. The internal devices have their own filters, but those belong to the instrument; this one sits in the rack, so anything routed through it — a sampled loop, a whole Sub Mixer, the master bus — can be swept the same way.

  • Type and Slope: Low Pass, High Pass, Band Pass or Notch, at 12 or 24 dB/oct. Band Pass is normalized, so its resonance narrows the band rather than turning it up.
  • Cutoff and Resonance: where the filter sits before anything modulates it, and how much it emphasizes its corner. Resonance is held short of self-oscillation so that a full-intensity sweep cannot make it scream.
  • Cutoff LFO and Resonance LFO: two independent LFOs with the same shapes and modes as the Synth's — Saw, Triangle, Square, Sine and Random, running free in Hz, locked to the tempo in Sync mode, or sweeping once in One-Shot.
  • Intensity: how far each LFO moves its target, from -100 % to +100 % through a cubic taper, so small settings are easy to dial in. Full intensity is five octaves of cutoff travel. Negative simply reverses the direction: where a rising LFO opened the filter, it now closes it.
  • Envelope Follower: Amount opens the filter with the signal's own level, the classic auto-wah, or closes it when turned negative. Attack and Release set how quickly it follows. The follower and both LFOs sum into the same cutoff, so they stack.
  • Stereo Phase: offsets the right channel's LFOs from the left channel's, up to half a cycle. The two channels then filter differently, which is genuine decorrelation and widens dramatically — but a mono sum averages the two and the sweep flattens out, so check mono before leaning on it.
  • Gain and Mix: output trim, and the blend against the dry signal for parallel filtering.

Phaser Parameters

An all-pass section passes every frequency at full level and only shifts its phase, by an amount that depends on the frequency. Summed back with the dry signal, the frequencies that come out half a cycle late cancel and the rest do not, so a cascade of them writes a comb of notches into the spectrum. Sweeping the cascade moves the notches, and that movement is the effect: nothing is being filtered out so much as repeatedly cancelled and released.

This is what separates it from the Chorus and from a flanger. A delay-based effect combs at harmonically spaced notches, hundreds of them, because the comb comes from a fixed time offset. Here each notch belongs to one pair of all-pass sections, and they are not harmonically related — which is why a phaser sounds hollow and vocal where a flanger sounds like a jet.

  • Stages: 2 to 12 all-pass sections. Every pair puts one notch into the spectrum, so this is literally how many notches there are: 4 stages is the classic two-notch sweep, 12 is thick and resonant.
  • Center and Depth: where the sweep sits, and how far either side of it the notches travel — up to three octaves at full depth.
  • Feedback: returns the cascade's output to its input, which sharpens the peaks between the notches. Its sign matters as much as its amount: the two polarities cancel at different frequencies and voice the effect quite differently, so try both.
  • Waveform, Mode and Rate: the sweep's LFO, with the same shapes and modes as the Synth's — free-running in Hz, locked to the tempo in Sync, or sweeping once in One-Shot.
  • Rate Divider: divides whatever the Rate works out to, by any whole number up to 64. It applies in both modes, which is what makes the very slow sweeps a phaser is often wanted for reachable: a free-running sweep can be stretched over minutes, and a tempo-locked one over several bars, which is a division the sync slider has no name for.
  • Stereo Phase: offsets the right channel's sweep from the left channel's. It starts at 90 degrees, the quadrature offset a stereo phaser is normally built with; 0 makes it mono and 180 opposes the channels completely.
  • Gain and Mix: output trim, and the blend against the dry signal. The notches are deepest at 50 %, where the dry and the swept signal meet at equal amounts — turn Mix up beyond that and the cancellation gets shallower rather than stronger.

Multiband Compressor Parameters

Three compressors on one signal, each working on its own part of the spectrum. Use it where a single compressor cannot win: a loud kick pumping the whole mix down, or a harsh vocal band that needs holding while the body is left alone.

  • Crossovers: two Linkwitz-Riley crossovers set where Low ends and High begins. They sum back flat, so with every band bypassed the effect is transparent.
  • Per band: Threshold, Ratio, Knee, Attack, Release and Makeup, plus Bypass and Solo for setting a band up on its own. Each band has its own gain reduction meter.
  • Side Chain Source: another device drives the detectors, split by the same crossovers, so the low band keys off the source's low end rather than off everything.
  • Detector and Output: Peak or RMS detection for all three bands, and an output trim.

There is deliberately no Mix control. The split path is phase-rotated against its own input by the crossovers, so blending it with an untouched dry signal would comb filter rather than soften the compression. Per-band makeup and the output gain cover what Mix would have been reached for.

Bass Grinder Parameters

A bass preamp distortion, for making a kick or a bass beefy and mean at once. The other nonlinear effects shape the full band, which is why none of them can do this: pushing one hard enough to get grind on top also shapes the fundamental, and the weight that made the sound worth distorting goes with it.

  • Split: takes the low band out of the clipper entirely. The fundamental comes through untouched while everything above it is hammered. At the bottom of its travel the split sits below the audio band and the effect becomes a plain full-band distortion.
  • Blend: how much of the clipped band replaces the clean one, the way a bass preamp's blend control does.
  • Drive: level into an asymmetric diode clipper. Its two halves clip at different thresholds, which is what generates the even harmonics that read as weight rather than fizz.
  • Color: switches in a fixed scooped voicing behind the clipper.
  • Bass, Mid, Mid Freq and Treble: the preamp's own tone stack, with a sweepable mid.
  • Mix and Output: the blend against the dry signal, and an output trim.

Stereo Exciter Parameters

An aural exciter, after the X32's, itself after the Aphex Aural Exciter. An equalizer can only turn up what is already there; where a recording has no top end to lift, a shelf has nothing to find. This takes the band above Tune, distorts it, and adds the harmonics that produces. Those are higher than anything in the band that made them, so the result reads as air and detail that was never in the signal.

  • Tune: where the band that feeds the generator starts. Peak sharpens the corner, Zero Fill mixes in a shallower path below it so the harmonics come from a wider band.
  • Timbre: left of centre runs odd harmonics, which read as edge and bite; right of centre runs even ones, which read as warmth. It blends rather than switches.
  • Harmonics: how much of what is generated is added back. Mix blends the whole result against the dry signal.
  • Solo Mode: passes only the harmonics being generated. Worth using: what an exciter adds is easy to overdo precisely because it is hard to hear underneath the signal.

The shaping runs oversampled, since harmonics of a band that already reaches several kilohertz would otherwise land above Nyquist and fold back down as inharmonic tones.

Stereo Enhancer Parameters

A "psycho EQ" rather than an equalizer, after the X32's, itself after the SPL Vitalizer. Where an equalizer boosts a band by turning it up, this one takes each band out of the signal, works on it, and adds it back.

  • Bass Gain and Bass Freq: the low band is saturated as it returns, so what comes back is the harmonics of the low end rather than more low end. Those harmonics let a small speaker imply a fundamental it cannot reproduce, at a fraction of the headroom the fundamental would cost.
  • Mid Gain and Mid Q: the midrange is dipped rather than lifted, because pulling the middle back is what opens up the two ends. Q sets how wide the dip is.
  • Hi Gain and Hi Freq: the top band, added back as a band of its own.
  • Spread: widens what is already off-centre by working on the side signal alone, so a mono source stays mono however far it is turned up.
  • Out Gain and Mix: output trim, and the blend against the dry signal.
  • Solo Mode: passes only what the enhancer adds, so it can be heard on its own. What a psycho EQ contributes is hard to judge underneath the signal it is contributing to.

Stereo Widener Parameters

Width, but per band. A single width control has to be set for whichever part of the spectrum matters most and is wrong everywhere else: widening that helps the top usually hurts the bottom, where the energy is and the localisation is not. Splitting the signal by two Linkwitz-Riley crossovers first is what lets the top be opened up while the bottom is left alone or pulled together.

  • Low/Mid and Mid/High: where the three bands are divided.
  • Width, per band: 0% sums the band to mono, 100% leaves it alone and 200% doubles its side signal. Width works on the side signal, so a band that arrives mono stays mono however far it is turned up.
  • Solo, per band: hear one band on its own.
  • Mono Bass and Mono Below: centres everything below the corner. This is a separate stage after the bands rather than one of them, so it holds whatever the low band's width control did.
  • Output: trim, since widening changes the peak level.
  • Correlation, per band: what the width control actually did. 1 is mono, 0 is fully decorrelated, and anything sustained below 0 will cancel when the mix is summed to mono.

There is deliberately no Mix control: the split path is phase-rotated against its own input by the crossovers, so blending it with an untouched dry signal would comb filter rather than soften the widening.

Dimension Parameters

Makes width where there is none. A width control can only spread what is already off-centre, so given a mono synth or a close-miked part it does nothing. This takes the centre of the mix itself, detunes one copy a few cents up and another the same few cents down, and adds the difference between them as side.

  • Detune: how far apart the two copies are, in cents. A few cents reads as one source made larger; past about fifteen it starts to read as two, which is a chorus rather than a widening.
  • Amount: how much of the generated side signal is added.
  • Low Cut: keeps the bottom out of it. Spreading low frequencies spends headroom on something the ear cannot place anyway.
  • Solo: passes only the side signal being built.

Working on the difference between the two copies is what makes this free: they appear in the side signal with opposite signs and nowhere else, so summing the output back to mono returns exactly the centre that came in. No setting of any control here can cost a mono listener anything, which is the opposite of how width is usually bought.

Stereo Field Meter

A passthrough meter for everything about a mix that a level meter cannot show: how wide it is, how much of it survives a fold-down to mono, and where in the spectrum the width actually lives. Width is routinely set by ear alone, and the ear is the wrong instrument for it -- what collapses in mono is whatever is out of phase between the channels, and nothing about that is audible until it is gone.

  • Goniometer: the field itself, rotated so a pair in phase runs straight up. The wedges either side of the horizontal axis are where material approaching pure side ends up, which is what cancels in mono.
  • Correlation: 1 is mono, 0 is fully decorrelated, below 0 cancels when summed. Named in a word above the readings: Mono, Narrow, Medium, Wide, Very Wide or Phase Risk.
  • Low, Mid and High: the same reading per band, since a mix is usually only in trouble at one end of the spectrum -- most often the bottom, where width costs the most and buys the least.
  • Mid and Side levels: how much of the signal is actually off-centre, which is what decides whether width is worth spending headroom on at all.
  • Speed: how long the readings average over. Fast follows a phrase, Slow follows a mix.
  • Zoom and Guides: scale of the trace, and whether the axes, amplitude rings and scales are drawn.

Analysis is gated on the dialog being open, so a meter left in a rack costs nothing.

Wave Designer Parameters

A transient shaper: Attack for the leading edge of a hit, Sustain for the tail behind it. Use it to make a snare crack, to tame an over-eager kick, or to shorten a room tail without a gate.

It is not a compressor. Each control runs two envelope followers over the signal and acts on the difference between them, and that difference only departs from zero while the signal is changing. A hit is therefore shaped by how sharply it rises and how long it takes to fall, never by how loud it is: the same setting works at any level, and a held note comes out untouched.

  • Attack: positive adds punch to the leading edge, negative tames it. Full range is 15 dB either way.
  • Sustain: positive holds the tail up, like a compressor letting peaks carry longer; negative shortens it for a more staccato sound.
  • Gain: output trim, +/-24 dB, to compensate for the level the shaping adds or removes.
  • Mix: blends the shaped signal against the dry one, for parallel transient shaping.

The meter shows the gain being applied at any moment, growing upwards when the shaper lifts and downwards when it tames.

Tube Stage Parameters

A valve preamp stage, for warming a signal the way a console's tube channel does. It differs from the Saturator's Tube mode in where the valve sits on its curve rather than in the curve itself.

A triode does not run symmetrically about zero: it idles at a grid bias, so the two halves of a waveform meet different parts of the curve. That asymmetry is what generates even harmonics, which is the warmth a valve is actually wanted for. A symmetric shaper can only generate odd harmonics, which read as harshness. Bias exposes that operating point directly.

  • Valve: Triode has a soft, gradual knee, the classic warm preamp valve. Pentode holds its shape longer and then gives way more abruptly, colouring less until pushed and running odd harmonics rather than even.
  • Drive: Level into the valve, up to 36 dB. This is what decides how much of the curve the signal actually uses.
  • Bias: The idle point. Centred is the most symmetric and cleanest; away from centre the halves are shaped differently and the even harmonics come up. Pushed to an extreme it runs hard against cutoff.
  • Tone: A tilt around 700 Hz. Turning it up lifts the top and drops the bottom together rather than simply adding level, so the centre position is exactly flat.
  • Mix: Dry/wet, for parallel warming.
  • Output: Trim either side of unity, since drive changes the level.

The shaping runs oversampled, so the harmonics it generates fold above Nyquist and are filtered out rather than aliasing back down into the audible band, and the DC offset an asymmetric curve leaves behind is blocked before it reaches the rest of the rack.

Analog Fuzz Parameters

An analog synth's drive knob, rather than a pedal in front of one. On a monosynth the distortion is not a box ahead of the filter: it is a stage pushing the VCF itself past what it can take, and the filter that rounds the result off is the same one whose resonance is being fed by it. Analog Fuzz is built that way round, so it does two things the other saturation effects cannot.

  • The resonance gives way under drive. The peak is bounded by the same ceiling the harmonics are, so pushing Drive squashes it instead of making it scream, and backing off opens it again. A distortion chained into Auto Filter keeps its peak at full height however hard the input is pushed.
  • The harmonics come out filtered rather than laid on top, because they are generated inside the loop and pass the poles on the way round. That is what keeps it warm instead of fizzy.
  • Drive: Level into the fuzz stage, up to 42 dB, and with it how hard the filter behind it is being run. The stage clips at -12 dBFS rather than at full scale, which is where the devices in this rack actually sit, so it is doing something well before the control is at the top. A quiet source gets louder as Drive comes up; one already into the knee only compresses further.
  • Fuzz: The shape of the stage's knee. Down low it is a soft, valve-like curve; up high it stays linear almost to the ceiling and then breaks at once, which is the square-ish clipping a fuzz circuit does.
  • Bias: Where on that curve the signal sits. Centred is odd harmonics and a hollow, woody tone; away from centre the even ones come up; far enough out the stage starves and gates, the way a fuzz on a dying battery does.
  • Cutoff: Corner of the filter being overdriven, 60 Hz to 12 kHz. Two poles, 12 dB per octave, the same slope a monosynth's filter runs.
  • Resonance: How much the corner is lifted, before the drive has its say on it.
  • Mix: Dry/wet, for parallel fuzz.
  • Output: Trim either side of unity.

For a lead in the style of an analog monosynth: Drive around two thirds, Fuzz low to middling, Bias just off centre, and the Cutoff somewhere above the fundamental with the Resonance high enough to hear it sing before the Drive folds it down. The stage and the filter both run oversampled, so the harmonics fold above Nyquist and are filtered out rather than aliasing back into the band, and the DC an off-centre Bias leaves behind is blocked before it reaches the rest of the rack.

Reverb Parameters

Noteahead features a studio-quality Feedback Delay Network (FDN) reverb, designed for lush tails and natural-sounding high-frequency absorption.

  • Preset Selection: Choose from 8 professional presets (e.g., Hall, Cathedral, Plate) using the ComboBox at the top. This will automatically adjust all parameters for the selected acoustic space.
  • Size: Controls the overall dimensions of the simulated room. Larger sizes result in more complex reflections.
  • Decay (ms): The time it takes for the reverb tail to fade away (0 to 10,000 ms).
  • Damping: Controls high-frequency absorption. Higher values result in a darker, warmer reverb sound as reflections lose high-frequency energy more quickly.
  • Pre-Delay (ms): The time gap between the dry signal and the start of the reverb (0 to 500 ms). This helps maintain clarity by separating the direct sound from the reverberation.
  • Width: Adjusts the stereo spread of the reverb output. 100% is standard stereo, while higher values expand the side signal for an ultra-wide effect.
  • Mix: Controls the wet/dry balance of the effect within its dedicated send bus.

Early Reflections Parameters

Puts a sound in a room without putting a tail on it. Depth and width are separate axes and a reverb only really addresses one of them: what tells the ear how far away something is is not how long the tail is but what arrives in the first eighty milliseconds. A long tail turned down low is a poor substitute, because it fills the gaps between notes rather than placing the notes themselves -- which is why more reverb so often buys atmosphere without buying distance.

  • Size: how far the reflection pattern is spread, from a small room to a hall.
  • Pre-Delay: how long the first reflection is held off. This is what separates a source from the room it is in; without it the two arrive together and the source sounds glued to the wall.
  • Damping: absorption, applied per reflection rather than to their sum. A reflection arriving late has bounced off more surfaces and pushed through more air, so it comes back darker -- losing the top with distance is one of the cues the effect exists to provide.
  • Diffusion: scatters the reflections into a continuous cloud. Sixteen discrete arrivals is a fraction of what a room returns, and too sparse to hear as a space rather than as an effect.
  • Width: how far the pattern is spread across the stereo field. The two channels are given different arrival times to begin with, so the pattern carries an image of its own.
  • Low Cut: keeps the reflections out of the bottom, where they only muddy what is already there.
  • Mix and Solo: the blend against the dry signal, and hearing the room without the source that caused it. On a send bus, set Mix to 100%: the send already returns only what the effect added, so Mix acts as the return level there.

Use it on a send, with the send amount as the distance control: more send is further back. One instance shared by everything is what sells the illusion, since a coherent room is a single room.

Compressor Parameters

The Compressor is a versatile dynamic processor used to control the signal's dynamic range. It uses a high-quality feed-forward algorithm with optional lookahead.

  • Threshold (dB): The level above which compression starts to occur (-60 to 0 dB).
  • Ratio: Determines the amount of gain reduction applied once the signal exceeds the threshold (1:1 to 20:1).
  • Knee (dB): Adjusts how the compressor transitions from uncompressed to compressed state (0 to 24 dB). A hard knee (0 dB) starts compressing immediately at the threshold, while a soft knee provides a smoother transition.
  • Attack: Sets how quickly the compressor responds to signals exceeding the threshold (0.1 to 500 ms).
  • Release: Determines how quickly the compressor returns to unity gain once the signal falls below the threshold (1 to 2000 ms).
  • Makeup (dB): Compensates for the level loss caused by compression (-12 to +12 dB).
  • Lookahead (ms): Delays the audio path slightly to allow the detector to "see" incoming peaks before they occur (0 to 10 ms), enabling more precise peak management.
  • Detector: Peak follows the waveform itself and catches every transient; RMS averages over a short window and follows perceived loudness instead, which is gentler on material with sharp attacks.
  • Reduction Meter: Provides real-time visual feedback of the current gain reduction in dB.

Auto Ducker Parameters

The Auto Ducker rides the level of the signal it sits on according to what a side chain source is doing. Point it at the kick to pump a pad, or at the lead to pull a bed out of the way. With no side chain source selected it listens to its own input.

  • Threshold (dB): The side chain level at which the ducker starts to engage (-60 to 0 dB).
  • Amount (dB): The gain applied once the side chain is fully above the threshold (-24 to +24 dB). Negative values duck the signal, positive values lift it.
  • Knee (dB): The range above the threshold over which the amount fades in (0 to 24 dB). A zero knee switches to the full amount at the threshold.
  • Attack: How quickly the gain moves towards the amount as the side chain engages (0.1 to 500 ms).
  • Release: How quickly the gain returns once the side chain falls back (1 to 2000 ms).
  • Hold (ms): Keeps the gain where it is before the release starts (0 to 500 ms), so a busy side chain does not chatter.
  • Side Chain Source: The device the detector listens to, with an LPF for keying off the low end only.
  • Gain Meter: Shows the gain currently applied, downwards while ducking and upwards while boosting.

Send Routing

Instead of having fixed effect chains, Noteahead uses a flexible Send Bus architecture. This allows you to route varying amounts of each instrument's signal to any of the master effects.

  • Effect Sends Dialog: In the Device Rack, each instrument instance has a dedicated Sends button. Clicking this opens a dialog with independent send knobs for all master effect slots.
  • Parallel Processing: Because effects are shared, you can apply the same "Hall Reverb" to multiple instruments at different levels, creating a cohesive sense of space in your mix while saving CPU resources.

Advanced Features

Pattern Peek

Enabled by default in Settings => General => Editor, Pattern Peek shows a dimmed glimpse of the previous and next patterns in the editor's offset areas above and below the current one, so you can see what you are cutting to and from.

Column Settings

Accessed by clicking the wheel icon in the column header or by right-clicking a note column and selecting Column settings, this dialog allows you to fine-tune the behavior of individual columns using three tabs:

  • Instrument: Set the Transpose value for all notes in the column. This value is added to the track-level transpose.
  • Timing: Adjust the Delay (ms) to shift all notes in the column forward or backward in time.
  • MIDI Effects: Manage Chord Automation, the Arpeggiator, and MIDI Delay for the column.

Chord Automation & Arpeggiator

Located in the MIDI Effects tab of the Column Settings, these tools allow you to generate complex harmony and movement from a single note.

  • Chord Automation: Set semi-tone offsets for up to three additional notes relative to your root note. Each chord note has its own velocity and delay settings, allowing for thick, humanized chords.
  • Arpeggiator: When enabled, the chord notes (including the root note) are played sequentially.
    • Patterns: Choose from Up, Down, Up-Down, or Random.
    • Events per beat: Determine the speed of the arpeggio relative to the BPM.

MIDI Delay

Also located in the MIDI Effects tab, this effect adds delayed echoes to all notes in the column.

  • Lines: Set the delay time between echoes in musical lines (e.g., 1.5 lines).
  • Feedback (%): Adjust the velocity of each subsequent echo relative to the previous one (0-100%).
  • Max repetitions: Set the maximum number of echoes to generate.

MIDI CC & Pitch Bend Automation

  • Add Automation: Select a range of lines, right-click, and choose "Add MIDI CC Automation" or "Add Pitch Bend Automation".
  • Interpolation & Modulation: Choose Linear for steady changes, or add Modulation (Sine Wave or Random) for organic, oscillating, or experimental movements.

MIDI Side-chain

Located in Track settings, this allows one track/column to trigger MIDI CC events on another, perfect for "pumping" effects or rhythmic modulation.

Internal Devices

Device Rack

Accessed via Devices => Device rack..., Right-click => Song => Device Rack..., or the Device Rack... button in Track Settings, the rack is the central hub for all internal instruments in Noteahead. Opening it from Track Settings is the quickest route when you are setting up a track: add the device, then pick its internal port for the track.

  • Managing Devices: The rack displays all active internal devices. Each entry shows the device name and a list of all tracks currently assigned to it. Click an active device entry to open its dedicated control dialog.
  • Dynamic Addition: Internal devices can be added to any empty slot by clicking the (+) icon. This opens the Device Gallery, where you can select from the available instruments — Sampler, Synth, Wavetable Synth, Bass Synth, Drum Synth, Piano Synth, String & Voice, String Ensemble and Sub Mixer — or use Import Device... to create a device straight from an exported settings file, or Copy Device... to duplicate an existing one.
  • Per-Slot Buttons: Insert FX opens the device's own effect rack, Sends its send levels to the master send effects, Settings the Device Settings dialog (see Gain Staging below), and Manage exports or imports the device's settings.
  • Level Meters: Each slot has a peak/RMS meter with a -18 dBFS marker to gain stage against. It is tapped after Gain and before the insert effects, so it shows the level your inserts actually see. See Reading the Level Meters below.
  • DSP Load: While the dialog is open, each slot shows the share of the audio callback its device consumes, and the footer shows the total, a peak hold and a dropout counter. The measurement only runs while the Device Rack is visible, so it costs nothing otherwise.
  • Multiple Instances: You can add as many instances of internal devices as your system resources allow. Each instance maintains its own settings, samples, and presets.
  • Removal: Click the trash can icon on an active slot to remove the device from the rack.

Reading the Level Meters

Each rack slot and mixer strip carries one meter that shows two readings of the same signal:

  • The filled bar is RMS — the average level, smoothed over 0.3 seconds. This is the reading that tracks how loud something sounds.
  • The thin white line is peak — the highest single sample. It falls back at 20 dB per second, so a transient stays readable instead of flashing past.
  • The marker is the gain staging target: -18 dBFS by default, and settable under Edit => Settings (-20 for SMPTE, or -14 and -12, are the other common choices).

The bar always sits below the line, and that is normal rather than a sign of anything being wrong. The distance between them is the crest factor of the material itself: a square wave has none, a sine sits 3 dB below its peak, white noise about 5 dB, and a sparse kick or snare 15 dB or more — partly because the RMS window averages in the quiet between the hits while the peak line is still holding the last one. Gain cannot close that gap, because it scales both readings by the same amount.

The Fader does not move this meter at all. The tap sits after Gain but before both the fader and the insert effects, so the meter always tells you how hard the inserts are being driven, no matter how you ride the fader afterwards. The clip LED beside it works the other way round: it watches what the device finally hands over, after the fader and the inserts.

Which reading do you aim at the marker? -18 dBFS is an average-level reference, so line the bar up with it for sustained material — pads, basses, held chords, a full mix. For transient material such as a kick, a snare or percussion, gain stage by the peak line instead and keep it somewhere around -12 to -6 dBFS; the bar will then sit far below the marker, which is exactly what a 15 dB crest factor looks like. Aiming a kick's RMS at -18 would put its peaks within a couple of dB of full scale.

Gain Staging

Every device has a Gain knob above a Fader knob, in signal-flow order: Gain trims the device into its insert effects, and the Fader balances it in the mix. Set the level with Gain so the slot meter reads the target — see Reading the Level Meters above for which of the two readings to aim — then use the Fader for balance.

The Fader runs from -inf to +10 dB, with unity gain three quarters of the way up its throw, so a device can be pushed past unity without reaching for Gain. Sampler pads have the same fader. Each rack row carries a clip LED next to its meter: it lights red as soon as that device's output touches full scale and stays lit until you click it, so a single overshoot cannot slip past while you are looking elsewhere.

The Settings button on a rack slot opens the Device Settings dialog, which decides where those two stages sit:

  • Fader position - Before insert effects: the fader feeds the insert effects, so moving it changes how hard a compressor or saturator is driven. This is how devices behaved before the setting existed and stays the default, so existing projects sound unchanged.
  • Fader position - After insert effects: the insert effects run at the level Gain sets, and the fader only balances what comes out of them. This is the setting to choose if you want to gain stage first and balance afterwards without disturbing the dynamics.
  • Send tap - Post-fader (default): sends follow the fader, so pulling a device down takes its reverb with it and the wet/dry ratio stays put.
  • Send tap - Pre-fader: sends keep their level whatever the fader does, so the device gets wetter as you pull it down.

Sampler

The Sampler is a versatile internal instrument for triggering audio samples.

  • Selection: Assign a track to a specific sampler by selecting its name (e.g., "Noteahead Sampler 1") in the Track Settings port list.
  • Pads: Each sampler features 16 pads, mapped to MIDI notes 36 to 51.
  • Loading Samples: Click an empty pad to open a file dialog and select a WAV or FLAC file. Once loaded, the pad is highlighted.
  • Playback: Press and hold a pad to play the sample, and release to stop. In the sequencer, use the corresponding MIDI note to trigger the sample.
  • Chromatic Mode: When enabled in the header, each pad maps to an octave and its sample is pitched chromatically across it. If only one pad is loaded, its sample covers the whole range — turning the Sampler into a simple multi-octave instrument.
  • Per-Pad Insert Effects: The small FX button on a loaded pad opens an insert effect rack for that pad alone.
  • Embedding: Embed wave data in the project file saves the sample data straight into the project, making it portable at the cost of size.
  • Panning: Each pad has its own base Pan setting (-100% to +100%). This can be adjusted using the slider on the right side of the pads.
  • Volume: Each pad has its own base Volume setting (0-100%).
  • Filters: Each pad features dual filters:
    • LPF Cutoff: Low-pass filter (0-100%, 100% is fully open).
    • HPF Cutoff: High-pass filter (0-100%, 0% is fully open).
  • Automation: The Sampler supports real-time MIDI CC automation:
    • CC 7: Volume.
    • CC 10: Pan.
    • CC 74: LPF Cutoff.
    • CC 81: HPF Cutoff.
    In "Channel Mode", CCs on channel 1 affect pad 1, channel 2 affects pad 2, and so on.
  • Management: Right-click a loaded pad to clear its assignment.

Synth

The Noteahead Synth is a powerful built-in polyphonic synthesizer (up to 6 voices) designed for classic and modern electronic sounds.

  • Selection: Assign a track to a specific synth by selecting its name (e.g., "Noteahead Synth 1") in the Track Settings port list.
  • Oscillators (VCO1, VCO2 & VCO3): Three oscillators with Triangle, Saw, and Square waveforms. Each features Octave as an organ footage (32', 16', 8', 4' or 2'), Pitch (fine-tuning), Shape (pulse-width or waveform modulation), Level, and Sync — VCO2 hard-syncs to VCO1 and VCO3 to VCO2. VCO2 adds Cross Mod Depth for FM-style timbres.
  • Multi Engine: An additional digital engine providing Low and High frequency content, Peak (peaking filter), and Decim (bit-crusher/decimator) textures. It includes its own Shape, Key Track and Level controls.
  • Filters:
    • LPF Cutoff & Resonance: A resonant low-pass filter for sculpting the timbre.
    • HPF Cutoff: A dedicated high-pass filter for removing low-end rumble or creating thin textures.
    • Key Track: Adjusts how much the filter cutoff follows the played note's pitch.
  • Envelopes:
    • Amp EG: A standard ADSR (Attack, Decay, Sustain, Release) envelope controlling the volume over time.
    • Mod EG: An AD (Attack, Decay) envelope with adjustable Intensity that can target Pitch 1, Pitch 2, or Filter Cutoff.
  • LFO 1 & LFO 2: Two independent Low-Frequency Oscillators with multiple waveforms and modes (Normal, 1-Shot and BPM-synced). Each can target Pitch (all three oscillators at once), Shape, Cutoff, Volume (tremolo), Resonance, Pan (auto-pan), or Pitch 1, Pitch 2 and Pitch 3 to detune a single oscillator against the others. Their modulations stack additively.
  • Analog Character: A Drift knob applies a slow per-voice pitch drift (up to ±5 cents) with an independent rate per voice, for an analog feel.
  • Voice / Global:
    • Voice Mode: Poly for chords, Unison, Dual, Supersaw and Drift for thick, stacked lead and bass sounds, and Mono for a single voice that a new note takes over, the way a monosynth plays.
    • Portamento: Smoothly glides between notes.
    • Pan Spread: Spreads voices across the stereo field for a wider sound.
    • Gain / Fader / Pan: Output stage of the device; see Gain Staging above.
  • Scope: A dedicated tab showing live left and right waveform traces side by side.
  • Delay Effect: A built-in delay with multiple types (Stereo, Mono, Ping Pong, and Tape), feedback, depth, and optional BPM Sync.
  • Presets:
    • Factory & User Banks: Use MIDI Bank Select (CC 0) to switch between Factory (0) and User (1) presets.
    • Patch Changes: Use standard MIDI Program Change messages to load presets within the active bank.
  • Automation: The Synth supports real-time MIDI CC automation:
    • CC 7: Volume.
    • CC 10: Pan.
    • CC 74: LPF Cutoff.
    • CC 81: HPF Cutoff.

BassSynth

The BassSynth is a specialized monophonic instrument designed for classic acid basslines and powerful low-end sounds.

  • Selection: Assign a track to a specific BassSynth by selecting its name (e.g., "Noteahead BassSynth 1") in the Track Settings port list.
  • Oscillator: Choose between Triangle, Saw, and Square waveforms. The Tuning control allows for fine-tuning the pitch.
  • Sub-Oscillator: Adds a sub-octave oscillator for extra weight.
    • Sub Level: Controls the volume of the sub-oscillator.
    • Sub Octave: Choose between -1 or -2 octaves below the root.
  • Filters:
    • LPF Cutoff & Resonance: A classic 24dB resonant low-pass filter, perfect for squelchy acid sweeps.
    • HPF Cutoff: A 12dB high-pass filter for sculpting the low-end.
    • Env Mod: Controls how much the internal decay envelope affects the LPF cutoff.
  • Envelope:
    • Decay: Controls the decay time for both the amplitude and the filter cutoff modulation.
  • Acid Implementation:
    • Accent: Triggered when note velocity is above 100. It boosts the volume and increases the filter envelope's effect.
    • Slide: Enabled via the Slide control. When notes overlap or are played legato, the pitch glides smoothly between them without retriggering the envelopes.
  • Distortion: Built-in saturation for aggressive textures.
    • Drive: Controls the amount of distortion.
    • Tone: Adjusts the brightness of the distorted signal.
    • Level: Sets the output level of the distortion stage.
  • Automation: Supports real-time MIDI CC automation for Volume (CC 7), Pan (CC 10), LPF Cutoff (CC 74), and HPF Cutoff (CC 81).

DrumSynth

The DrumSynth is a specialized internal instrument for synthesizing drum sounds, featuring 11 independent voices with dedicated synthesis engines.

  • Selection: Assign a track to a specific DrumSynth by selecting its name (e.g., "Noteahead DrumSynth 1") in the Track Settings port list.
  • Voices: Features 11 voices: Kick, Snare, Closed Hi-Hat, Clap, Open Hi-Hat, Low Tom, Mid Tom, High Tom, Crash, Ride, and Reverse Crash.
  • Common Voice Controls:
    • Level & Pan: Individual volume and stereo positioning for each voice.
    • LPF & HPF Cutoff: Dedicated low-pass and high-pass filters for each voice.
    • Tune: Pitch control for the drum engine.
    • Decay & Attack: Control the amplitude envelope of the drum sound.
    • Resonance: Filter resonance for the voice's LPF.
  • Advanced Controls:
    • Kick: Click Tune, Pitch Depth, and Pitch Decay.
    • Snare: Snappy (noise level) and Tone.
    • Toms: Pitch Depth and Pitch Decay.
  • Per-Voice Insert Effects: The small FX button next to a voice opens an insert effect rack for that voice alone.
  • Automation: DrumSynth supports simplified direct MIDI CC automation for essential parameters of each voice. Automation targets include:
    • CC 7: Global Volume.
    • CC 10: Global Pan.
    • Voice Pan, LPF, and HPF: Direct CCs are assigned to each voice (e.g., Kick uses CC 14-16, Snare uses CC 17-19, etc.). The Property Service provides descriptive names for these CCs in the automation editor.

Wavetable Synth

An 8-voice wavetable synthesizer for digital and evolving timbres.

  • Oscillators: Two independent wavetable oscillators with Classic and Spectral wavetable sets, plus a noise generator.
  • Filters: Cascaded LPF and HPF with resonance.
  • Modulation: Amp and Mod envelopes and two LFOs, with the same target list as the Synth.
  • Voices: Poly and Unison modes with stereo pan spread and portamento.

Piano Synth

A physically modelled (waveguide) piano rather than a sampled one, so it stays small and responds continuously to velocity.

  • String: Brightness, Decay, Inharmonicity and Release shape the tone from a soft upright to a bright grand.
  • Global: LPF/HPF shaping, stereo pan spread, and the usual Gain/Fader/Pan output stage.

Piano Synth V2

A second, larger piano, voiced against a recording of a Yamaha CP88. Where the Piano Synth runs a waveguide — one delay line standing in for the whole string — this one runs a bank of resonators, one per partial, so each partial can be given its own decay and its own place in the harmonic series.

That is what a real string does and what a single waveguide cannot: high partials die away long before low ones, stiffness pushes each partial progressively sharp of a perfect multiple, a struck unison decays in two stages as the strings fall out of step, and the lowest fundamental is radiated so weakly that the note is carried by its harmonics instead.

  • Hammer Hardness: how hard the hammer is, from felt to something closer to wood. It sets which partials the strike excites, so it changes the attack rather than simply the level of the top end.
  • Richness: how many partials are given to the note, trading weight against CPU.
  • Release Time: how quickly the dampers stop a note when the key is released.
  • Decay and Double Decay: the length of the tail, and how pronounced the two-stage decay of a struck unison is.
  • Brightness: the balance of the partials, from a mellow upright to a bright grand.
  • Inharmonicity: string stiffness, which pushes the upper partials sharp. It is what makes a piano sound like a piano rather than like an organ.
  • Unison Detune: how far the strings of a unison are detuned against each other, which is where the beating and the shimmer come from.
  • Stretch Tuning: the octave stretch a piano tuner applies to keep the stretched partials in agreement across the keyboard.

Kick808

A TR-808-style bass drum. Where the Drum Synth's kick follows the 909 lineage — a pitch-swept oscillator under an amplitude envelope — this one models the 808's bridged-T network as a high-Q resonator that the trigger pulse rings. That is what gives it the very long, near-pure sub tail, and it means overlapping hits sum into the ringing tail instead of cutting it off.

It is deliberately a pitched, monophonic instrument rather than a drum machine voice, because the 808 kick is played as a bass line at least as often as it is played as a drum. Notes are one-shot: Decay owns the tail and a note off does not cut it, exactly like the hardware. Only Stop all notes chokes a ringing hit.

  • Tuning: Pitch offset, up to two octaves either way. On the RD-8 this knob sits in the Accent column, which is only panel layout — it is a bass drum parameter and has nothing to do with accent. Accent itself is just velocity, which the note column already gives you.
  • Tone: Shortens and brightens the excitation pulse and raises the amount of it that leaks straight to the output, so it controls how much click sits on the front of the hit.
  • Decay: The resonator's own damping, sweeping from a bare click through to a boom of a few seconds.
  • Drive: Saturation for the modern, distorted 808 sound. Fully bypassed at zero.
  • Pitch Depth and Pitch Decay: The downward sweep at the start of the hit — the "pop" of the attack.
  • Key Track: On, the voice follows the note column and Glide slurs between notes, which is how 808 bass lines are written. Off, it stays at a fixed C2 and behaves like the hardware's single tuned voice.
  • LPF/HPF Cutoff: The same output filters the other internal devices have, in the Global section.

Being monophonic, a new hit takes the voice over rather than piling onto the one before it: the ring that is still sounding fades out from under it over a few milliseconds. That is what keeps every hit weighing the same in a fast pattern, and it means a run of kicks stays even instead of drifting in and out of reinforcement.

Every parameter above is reachable over MIDI CC, so a whole kick can be automated per line from a note column. LPF and HPF sit on the same controller numbers the other devices use for them.

String & Voice

A vintage string and choir ensemble inspired by the Roland VP-330 and Behringer VC340.

  • Registers: Independent strings and voice (choir) sections that can be mixed freely.
  • Ensemble: A BBD-style ensemble chorus for the classic wide, shimmering movement.
  • Vocoder: A side-chain vocoder section driven by another track.

String Ensemble

A divide-down string machine in the Solina tradition. Twelve master oscillators are tapped at 16', 8' and 4' by every key, so octaves stay phase-locked and polyphony is effectively unlimited — hold as many keys as you like.

  • Bass Section (keys below B3): Contrabass 16' and Cello 8', with a Volume Bass knob to balance them against the upper section.
  • Upper Section (keys from B3 up): Horn 16', Viola 8', Trumpet 8' and Violin 4'. Any combination of registers can be on at once.
  • Envelope: Crescendo sets the attack and Sustain Length the release. Velocity sets how much playing dynamics affect the level; at zero every note plays at full level.
  • Modulation: An Ensemble chorus for the instrument's signature width, and a Phaser with Color and Rate controls.
  • Global: Gain, Fader, Pan and LPF/HPF cutoff. MIDI CC automation for Volume (CC 7) and Pan (CC 10).

Sub Mixer

Not an instrument but a grouping device: it sums other devices so a whole set is mixed and processed as one entity — for example everything except the lead synth through a single compressor.

  • Members: Choose which devices feed the Sub Mixer. Members keep their own send levels to the master send effects.
  • Processing: The Sub Mixer has its own insert effect rack plus Gain, Fader and Pan.
  • Nesting: Sub Mixers can feed other Sub Mixers.
  • Automation: Its Volume and Pan can be ridden from a track over MIDI CC, so assign a track to it as you would to an instrument.

Mixer

Opened from Devices => Mixer..., the Mixer shows every device in the rack side by side as channel strips, so a whole mix can be balanced without opening each device in turn.

  • Strips: each carries the same Gain, Fader and Pan controls as the device's own dialog — Gain trims the device into its insert effects, the Fader balances it, Pan places it — plus its level meter and clip LED. A strip is labelled with the device name and the tracks that play it.
  • Buttons: Device opens the instrument's editor, Insert FX its own effect rack, and Sends its levels to the master send effects.
  • Clear clips: resets every latched clip LED at once, so a pass can be checked from a clean slate.

Synchronization

Noteahead can be synchronized with external audio hosts and MIDI hardware. These options are available in Settings => MIDI => Synchronization.

  • Jack Transport Sync: (Requires **JACK** audio backend) When enabled, Noteahead acts as a JACK client and will follow the Play, Stop, and Rewind commands from a JACK transport master (like Carla or QjackCtl).
  • Jack BPM Sync: (Requires **JACK** audio backend and **Jack Transport Sync**) Noteahead will follow the BPM of the JACK host and synchronize its internal timeline to the JACK sample clock for drift-free, sample-accurate playback. The BPM display in the toolbar will update to reflect the host's tempo.
  • MIDI Transport Sync: Allows Noteahead to be started and stopped by external MIDI controllers. Support is included for standard MIDI Start/Stop messages as well as common hardware CC mappings (e.g., Arturia Keystep).

Tools & Audio

  • Audio Backend: Choose your preferred audio driver in Settings => Audio => Backend.
    • Auto: Automatically selects the best available backend.
    • ALSA / PulseAudio: Standard Linux audio backends. Device selection and buffer size can be configured directly in Noteahead.
    • JACK: High-performance low-latency backend. Device routing and buffer size are managed externally (e.g., via Carla or qpwgraph). **Required** for Jack Transport and BPM synchronization.
  • Audio Recorder & Player: Enable in Settings => Audio to capture your performance directly from your system's audio input and play back recorded files.
    • Wave View: When enabled, a waveform of the recording is shown at the bottom of the editor.
    • Playback: Use the play button next to the waveform to start or stop audio playback.
    • Navigation: Left-click on the wave view to seek both the audio playback and the main sequencer to that position. Right-click to open the folder containing the recorded file.
    • JACK mode: When the **JACK** backend is active, Noteahead provides virtual input ports (input_1/input_2) and output ports (output_1/output_2). Route your audio sources to these inputs using a patchbay.
    • Persistence: The path to the last recorded file is saved with your project, allowing for seamless workflow across sessions.
  • Playback Quality: Settings => Audio => Playback quality sets the oversampling factor used during playback: Draft (1x), Normal (2x) or High (4x). Lower saves CPU while composing; higher reduces aliasing in the internal synths. The export has its own quality setting, so you can work at 1x and still render at 4x.
  • Spread playback across CPU cores: Also in Settings => Audio, off by default. When enabled, devices are processed on several threads during playback. It needs real-time scheduling privileges; without them playback quietly stays single-threaded. Offline rendering always uses all cores.
  • Audio Renderer: Export your song to WAV or FLAC via File => Render audio....
    • Accuracy: Offline rendering ensures sample-accurate timing and full reproduction of all internal instrument behaviors, including complex automations.
    • Render Mode: Master Mix writes the whole mix; Individual Tracks writes one file per track that uses an internal device, which is how you get stems for an external DAW.
    • Audio Settings: Format (WAV or FLAC), sample rate, bit depth (16/24/32-bit PCM or 32-bit float, depending on format) and Quality (1x, 2x or 4x oversampling).
    • Export Options: Normalize audio to a target level, Trim duration to a given length, Fade out over the last seconds of the render, Silence to leave a stretch of digital black after the tail, and Analyze loudness to get a LUFS, LRA and dBTP report after the render.
    • Metadata: Title, artist, album, date, genre, track number and comment are stored with the song and written into the exported file.
    • Song-Specific: All of these options are saved with the song, like the tags, so one song can never inherit another's trim length. A new song starts from FLAC, 48 kHz, 24-bit, 4x quality with loudness analysis on.
  • Delay Calculator: Quickly find millisecond values for various beat divisions based on the current BPM.
  • Note Frequency Calculator: Reference tool for sound design and tuning.
  • Gain Converter: Converts decibels to a linear multiplier, for reading gear and plugin documentation that quotes one when Noteahead asks for the other.

Appearance

Settings => Theme sets the colors the editor is drawn in.

  • Accent: the highlight color used across the interface, from dialog headings to the labels above every knob.
  • Cursor: the color of the editor cursor.
  • Accent blend: how far the track and automation colors are pulled towards the accent color. 0 % keeps the original palette, 100 % puts every color on the accent hue.

Under Settings => General: the number of lines visible in the editor, the track header font size, Pattern Peek, how automations are drawn (Tint or Curve, and the curve's line thickness), and the gain staging target the Device Rack meters mark.
