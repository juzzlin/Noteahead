Noteahead User Manual

Noteahead is a "simple" MIDI tracker and sequencer for Linux focusing on ease of use. It is designed for fast, keyboard-driven sequencing of external synths and drum machines, with clear handling of patch changes, automation, and CCs — no cryptic hex values required.

It also ships with a rack of internal instruments and studio-quality effects, so a whole song can be written, mixed and rendered to audio without leaving the application. See Internal Devices and Effect Racks below.

The Toolbar

The toolbar at the top of the window provides essential controls for song structure, pattern editing, and global settings.

Song Section

  • Player Controls: Play, Previous, Stop, and Loop buttons.
  • POS: The current position in the Song Play Order (0-indexed).
  • Skipped Patterns: Right-click on a position button to toggle its "skipped" state. Skipped positions are highlighted in red and will be automatically bypassed during playback. This also immediately updates the total song duration. Note that skipping can only be toggled when the song is stopped.
  • PAT: The Pattern Index assigned to the current song position. Changing this allows you to reuse patterns throughout your song.
  • LEN: The total length of the song (number of positions in the play order).
  • [+] / [-]: Insert or remove a position in the song play order.

Pattern Section

  • Pattern Name: Click the orange text to rename the active pattern.
  • PAT: The Active Pattern Index being edited. You can switch between patterns here to work on different parts of your project.
  • LEN: The length of the current pattern in lines (e.g., 64). Each pattern can have a different length.

Edit Section

  • STEP: The edit step. When you enter a note, the cursor automatically moves down by this number of lines. Set to 0 to stay on the same line.
  • VEL: The default velocity (0-127) assigned to new notes you input.
  • OCT: The base octave (0-8) for note entry.

Tempo Section

  • BPM: Beats Per Minute. Sets the overall playback speed.
  • LBP: Lines Per Beat. Defines how many tracker lines make up one musical beat (usually 4 for a standard 4/4 signature).

Editor Columns

Each Note Column consists of four data fields per line:

C-4 100 00 064

  1. Note (e.g., C-4): The musical pitch and octave. "OFF" indicates a Note Off event, which stops the playing note.
  2. Velocity (000-127): How hard the note is struck. 127 is maximum, 0 is silent.
  3. Delay (00-XX): Sub-line timing delay. This allows you to "humanize" your sequence by starting a note slightly after the line's exact beat. The maximum value depends on your Ticks Per Line setting.
  4. Pan (000-127, first column only): Stereo position sent as MIDI CC #10. 0 is hard left, 64 is center, 127 is hard right. Pan is only editable and displayed on the first note column of each track; additional columns show ---. A pan value can be placed on any line — including lines without a note — so that panning changes can be sent on every step regardless of note events.

Core Concepts

Tracks and Note Columns

Each track in Noteahead represents one MIDI instrument. While you can change patches on-the-fly, the track-based approach keeps your sequence organized.

  • Track Settings: Set the MIDI port, channel, bank, patch, volume, pan, and cutoff.
  • Drum track: When enabled in Track Settings, the track is excluded from pattern-wide transposition commands. This is useful for tracks triggering drum kits where transposition would change the instrument instead of the pitch.
  • Note Columns: Use the [+] and [-] buttons in the track header to manage multiple note columns per track, allowing for polyphonic sequencing or complex layered parts.
  • Velocity Scaling: Velocity is calculated as the product of track scale, column scale, and individual note velocity.

Internal Timing

Noteahead uses a high-precision internal timing strategy. The song is rendered into events just before playback, and the player thread syncs to these pre-calculated timestamps to ensure jitter-free and drift-free MIDI output.

Basic Workflow

Getting Started

  1. Setup MIDI: Click the settings icon on a track header to select your MIDI output device and channel.
  2. Edit Mode: Press ESC to enter edit mode. The cursor will change color to indicate you can now input notes.
  3. Inputting Notes: Use your PC keyboard as a virtual piano (e.g., Z is C, S is C#, X is D).
  4. Playback: Press SPACE to start or stop playback.

Main Context Menu

The main context menu can be accessed by right-clicking anywhere in the editor view. It provides a comprehensive set of tools for manipulating your sequence at different scopes.

  • Line: Insert or remove specific events (like Patch Changes), set sub-line delays, and manage line-specific automations.
  • Column: Perform Cut/Copy/Paste and transposition on the current note column. You can also Add Note OFF to quickly insert a note-off event on the first line of the column, Interpolate velocity or Interpolate pan across the entire column (pan interpolation always targets the first column and fills every line in the range with a pan value), or manage column-wide automations.
  • Track: Manage the current track (Insert/Delete), Add Note OFF to all columns in the track (first line), transpose all columns within the track, and edit track-specific automations.
  • Pattern: Add Note OFF to all columns in the entire pattern (first line), transpose, or perform clipboard operations for the entire active pattern.
  • Song: Access the Device Rack... to manage internal instruments or perform song-wide transposition.
  • Delete unused patterns: Found in the Edit menu, this tool scans the play order and removes all patterns that are not assigned to any song position. This is useful for cleaning up patterns that were created during the composing process but are no longer part of the song.
  • Selection: When a range of lines/columns is selected, this menu allows you to perform actions specifically on that selection, such as adding automations or interpolating velocity.
  • Global Automation: At the bottom of the menu, you can find options to edit ALL MIDI CC or Pitch Bend automations in the project.

Effect Racks

Effect Rack

Accessed via Effects => Master effect rack..., the Effect Rack is the central hub for global audio processing. It has two tabs: Insert Effects, processed in order on the master output, and Send Effects, which all internal instruments can share via their sends.

The same rack appears in several places, and works identically everywhere:

  • Master rack: insert and send effects for the whole mix.
  • Device insert rack: the Insert FX button in the Device Rack gives every device its own chain.
  • Per-pad and per-voice racks: the small FX button on a Sampler pad or a Drum Synth voice opens an insert rack for that pad or voice alone.
  • Managing Effects: The rack displays a list of active effect slots. Click an active slot to open its dedicated parameter dialog. Each slot has its own enable switch, and the whole rack can be bypassed with the Enabled switch in the header — handy for switching effects off when rendering individual tracks.
  • Dynamic Addition: Effects can be added to any empty slot by clicking the (+) icon. This opens the Effects Gallery, where you can pick an effect type, Import Effect... from an exported settings file, or Copy Effect... to duplicate another effect in the same rack.
  • Manage Menu: Reorder a slot with Move Up, Move Down, Move to Top and Move to Bottom, or Export Settings... / Import Settings... to reuse an effect elsewhere.
  • Multiple Instances: You can add multiple independent effect instances. For example, you can have several FDN Reverbs with different acoustic settings.
  • Removal: Click the trash can icon on an active slot to remove the effect from the rack.

Available Effects

  • Equalizers: EQ 8-Band Parametric (Bell, Shelf, Cut and Notch types per band, plus Mid/Side modes), Vintage Passive EQ (EQP-1A style, with interacting low Boost/Atten shelves and a high bell), Air Band EQ (fixed parallel-summed bands added back to the dry signal) and Simple EQ (a single "Sounds Good" knob sweeping a loudness-smile curve).
  • Reverbs: Reverb (the FDN reverb described below) and Endless Reverb (a large modulated ambient reverb with a Freeze switch for an infinite tail).
  • Dynamics: Compressor (with side-chain support), Auto Ducker (side-chain driven ducking or boosting), Limiter (lookahead brickwall with gain reduction metering) and Clipper.
  • Saturation: Drive (Soft, Hard, Fold and Dist algorithms) and Saturator.
  • Modulation & Time: Chorus, Delay (Mono, Ping Pong and Tape modes, with BPM sync) and All-Pass Filter.
  • Stereo: Panner and Auto Panner.
  • Metering & Analysis: LUFS Meter, dBTP Meter (true peak) and RTA (real-time analyzer). Use these as inserts to watch the signal at any point in the chain.

Reverb Parameters

Noteahead features a studio-quality Feedback Delay Network (FDN) reverb, designed for lush tails and natural-sounding high-frequency absorption.

  • Preset Selection: Choose from 8 professional presets (e.g., Hall, Cathedral, Plate) using the ComboBox at the top. This will automatically adjust all parameters for the selected acoustic space.
  • Size: Controls the overall dimensions of the simulated room. Larger sizes result in more complex reflections.
  • Decay (ms): The time it takes for the reverb tail to fade away (0 to 10,000 ms).
  • Damping: Controls high-frequency absorption. Higher values result in a darker, warmer reverb sound as reflections lose high-frequency energy more quickly.
  • Pre-Delay (ms): The time gap between the dry signal and the start of the reverb (0 to 500 ms). This helps maintain clarity by separating the direct sound from the reverberation.
  • Width: Adjusts the stereo spread of the reverb output. 100% is standard stereo, while higher values expand the side signal for an ultra-wide effect.
  • Mix: Controls the wet/dry balance of the effect within its dedicated send bus.

Compressor Parameters

The Compressor is a versatile dynamic processor used to control the signal's dynamic range. It uses a high-quality feed-forward algorithm with optional lookahead.

  • Threshold (dB): The level above which compression starts to occur (-60 to 0 dB).
  • Ratio: Determines the amount of gain reduction applied once the signal exceeds the threshold (1:1 to 20:1).
  • Knee (dB): Adjusts how the compressor transitions from uncompressed to compressed state (0 to 24 dB). A hard knee (0 dB) starts compressing immediately at the threshold, while a soft knee provides a smoother transition.
  • Attack: Sets how quickly the compressor responds to signals exceeding the threshold (0.1 to 500 ms).
  • Release: Determines how quickly the compressor returns to unity gain once the signal falls below the threshold (1 to 2000 ms).
  • Makeup (dB): Compensates for the level loss caused by compression (-12 to +12 dB).
  • Lookahead (ms): Delays the audio path slightly to allow the detector to "see" incoming peaks before they occur (0 to 10 ms), enabling more precise peak management.
  • Reduction Meter: Provides real-time visual feedback of the current gain reduction in dB.

Auto Ducker Parameters

The Auto Ducker rides the level of the signal it sits on according to what a side chain source is doing. Point it at the kick to pump a pad, or at the lead to pull a bed out of the way. With no side chain source selected it listens to its own input.

  • Threshold (dB): The side chain level at which the ducker starts to engage (-60 to 0 dB).
  • Amount (dB): The gain applied once the side chain is fully above the threshold (-24 to +24 dB). Negative values duck the signal, positive values lift it.
  • Knee (dB): The range above the threshold over which the amount fades in (0 to 24 dB). A zero knee switches to the full amount at the threshold.
  • Attack: How quickly the gain moves towards the amount as the side chain engages (0.1 to 500 ms).
  • Release: How quickly the gain returns once the side chain falls back (1 to 2000 ms).
  • Hold (ms): Keeps the gain where it is before the release starts (0 to 500 ms), so a busy side chain does not chatter.
  • Side Chain Source: The device the detector listens to, with an LPF for keying off the low end only.
  • Gain Meter: Shows the gain currently applied, downwards while ducking and upwards while boosting.

Send Routing

Instead of having fixed effect chains, Noteahead uses a flexible Send Bus architecture. This allows you to route varying amounts of each instrument's signal to any of the master effects.

  • Effect Sends Dialog: In the Device Rack, each instrument instance has a dedicated Sends button. Clicking this opens a dialog with independent send knobs for all master effect slots.
  • Parallel Processing: Because effects are shared, you can apply the same "Hall Reverb" to multiple instruments at different levels, creating a cohesive sense of space in your mix while saving CPU resources.

Advanced Features

Pattern Peek

Enabled by default in Settings => General => Editor, Pattern Peek shows a dimmed glimpse of the previous and next patterns in the editor's offset areas above and below the current one, so you can see what you are cutting to and from.

Column Settings

Accessed by clicking the wheel icon in the column header or by right-clicking a note column and selecting Column settings, this dialog allows you to fine-tune the behavior of individual columns using three tabs:

  • Instrument: Set the Transpose value for all notes in the column. This value is added to the track-level transpose.
  • Timing: Adjust the Delay (ms) to shift all notes in the column forward or backward in time.
  • MIDI Effects: Manage Chord Automation, the Arpeggiator, and MIDI Delay for the column.

Chord Automation & Arpeggiator

Located in the MIDI Effects tab of the Column Settings, these tools allow you to generate complex harmony and movement from a single note.

  • Chord Automation: Set semi-tone offsets for up to three additional notes relative to your root note. Each chord note has its own velocity and delay settings, allowing for thick, humanized chords.
  • Arpeggiator: When enabled, the chord notes (including the root note) are played sequentially.
    • Patterns: Choose from Up, Down, Up-Down, or Random.
    • Events per beat: Determine the speed of the arpeggio relative to the BPM.

MIDI Delay

Also located in the MIDI Effects tab, this effect adds delayed echoes to all notes in the column.

  • Lines: Set the delay time between echoes in musical lines (e.g., 1.5 lines).
  • Feedback (%): Adjust the velocity of each subsequent echo relative to the previous one (0-100%).
  • Max repetitions: Set the maximum number of echoes to generate.

MIDI CC & Pitch Bend Automation

  • Add Automation: Select a range of lines, right-click, and choose "Add MIDI CC Automation" or "Add Pitch Bend Automation".
  • Interpolation & Modulation: Choose Linear for steady changes, or add Modulation (Sine Wave or Random) for organic, oscillating, or experimental movements.

MIDI Side-chain

Located in Track settings, this allows one track/column to trigger MIDI CC events on another, perfect for "pumping" effects or rhythmic modulation.

Internal Devices

Device Rack

Accessed via Devices => Device rack... or Right-click => Song => Device Rack..., the rack is the central hub for all internal instruments in Noteahead.

  • Managing Devices: The rack displays all active internal devices. Each entry shows the device name and a list of all tracks currently assigned to it. Click an active device entry to open its dedicated control dialog.
  • Dynamic Addition: Internal devices can be added to any empty slot by clicking the (+) icon. This opens the Device Gallery, where you can select from the available instruments — Sampler, Synth, Wavetable Synth, Bass Synth, Drum Synth, Piano Synth, String & Voice, String Ensemble and Sub Mixer — or use Import Device... to create a device straight from an exported settings file, or Copy Device... to duplicate an existing one.
  • Per-Slot Buttons: Insert FX opens the device's own effect rack, Sends its send levels to the master send effects, Settings the Device Settings dialog (see Gain Staging below), and Manage exports or imports the device's settings.
  • Level Meters: Each slot has a peak/RMS meter with a -18 dBFS marker to gain stage against. It is tapped after Gain and before the insert effects, so it shows the level your inserts actually see.
  • DSP Load: While the dialog is open, each slot shows the share of the audio callback its device consumes, and the footer shows the total, a peak hold and a dropout counter. The measurement only runs while the Device Rack is visible, so it costs nothing otherwise.
  • Multiple Instances: You can add as many instances of internal devices as your system resources allow. Each instance maintains its own settings, samples, and presets.
  • Removal: Click the trash can icon on an active slot to remove the device from the rack.

Gain Staging

Every device has a Gain knob above a Fader knob, in signal-flow order: Gain trims the device into its insert effects, and the Fader balances it in the mix. Aim for about -18 dBFS on the slot meter with Gain, then use the Fader for balance.

The Settings button on a rack slot opens the Device Settings dialog, which decides where those two stages sit:

  • Fader position - Before insert effects: the fader feeds the insert effects, so moving it changes how hard a compressor or saturator is driven. This is how devices behaved before the setting existed and stays the default, so existing projects sound unchanged.
  • Fader position - After insert effects: the insert effects run at the level Gain sets, and the fader only balances what comes out of them. This is the setting to choose if you want to gain stage first and balance afterwards without disturbing the dynamics.
  • Send tap - Post-fader (default): sends follow the fader, so pulling a device down takes its reverb with it and the wet/dry ratio stays put.
  • Send tap - Pre-fader: sends keep their level whatever the fader does, so the device gets wetter as you pull it down.

Sampler

The Sampler is a versatile internal instrument for triggering audio samples.

  • Selection: Assign a track to a specific sampler by selecting its name (e.g., "Noteahead Sampler 1") in the Track Settings port list.
  • Pads: Each sampler features 16 pads, mapped to MIDI notes 36 to 51.
  • Loading Samples: Click an empty pad to open a file dialog and select a WAV or FLAC file. Once loaded, the pad is highlighted.
  • Playback: Press and hold a pad to play the sample, and release to stop. In the sequencer, use the corresponding MIDI note to trigger the sample.
  • Chromatic Mode: When enabled in the header, each pad maps to an octave and its sample is pitched chromatically across it. If only one pad is loaded, its sample covers the whole range — turning the Sampler into a simple multi-octave instrument.
  • Per-Pad Insert Effects: The small FX button on a loaded pad opens an insert effect rack for that pad alone.
  • Embedding: Embed wave data in the project file saves the sample data straight into the project, making it portable at the cost of size.
  • Panning: Each pad has its own base Pan setting (-100% to +100%). This can be adjusted using the slider on the right side of the pads.
  • Volume: Each pad has its own base Volume setting (0-100%).
  • Filters: Each pad features dual filters:
    • LPF Cutoff: Low-pass filter (0-100%, 100% is fully open).
    • HPF Cutoff: High-pass filter (0-100%, 0% is fully open).
  • Automation: The Sampler supports real-time MIDI CC automation:
    • CC 7: Volume.
    • CC 10: Pan.
    • CC 74: LPF Cutoff.
    • CC 81: HPF Cutoff.
    In "Channel Mode", CCs on channel 1 affect pad 1, channel 2 affects pad 2, and so on.
  • Management: Right-click a loaded pad to clear its assignment.

Synth

The Noteahead Synth is a powerful built-in polyphonic synthesizer (up to 6 voices) designed for classic and modern electronic sounds.

  • Selection: Assign a track to a specific synth by selecting its name (e.g., "Noteahead Synth 1") in the Track Settings port list.
  • Oscillators (VCO1 & VCO2): Two high-quality oscillators with Triangle, Saw, and Square waveforms. Each oscillator features Octave, Pitch (fine-tuning), Shape (pulse-width or waveform modulation), and Sync. VCO2 adds Cross Mod Depth for FM-style timbres.
  • Multi Engine: An additional digital engine providing Low and High frequency content, Peak (peaking filter), and Decim (bit-crusher/decimator) textures. It includes its own Shape and Level controls.
  • Mixer: Balance the output of VCO1 and VCO2.
  • Filters:
    • LPF Cutoff & Resonance: A resonant low-pass filter for sculpting the timbre.
    • HPF Cutoff: A dedicated high-pass filter for removing low-end rumble or creating thin textures.
    • Key Track: Adjusts how much the filter cutoff follows the played note's pitch.
  • Envelopes:
    • Amp EG: A standard ADSR (Attack, Decay, Sustain, Release) envelope controlling the volume over time.
    • Mod EG: An AD (Attack, Decay) envelope with adjustable Intensity that can target Pitch 1, Pitch 2, or Filter Cutoff.
  • LFO 1 & LFO 2: Two independent Low-Frequency Oscillators with multiple waveforms and modes (Normal, Fast, 1-Shot, and BPM-synced). Each can target Pitch, Shape, Cutoff, Volume (tremolo), Resonance or Pan (auto-pan). Their modulations stack additively.
  • Analog Character: A Drift knob applies a slow per-voice pitch drift (up to ±5 cents) with an independent rate per voice, for an analog feel.
  • Voice / Global:
    • Voice Mode: Choose between Poly for chords, Unison for thick, stacked lead and bass sounds, or Dual.
    • Portamento: Smoothly glides between notes.
    • Pan Spread: Spreads voices across the stereo field for a wider sound.
    • Gain / Fader / Pan: Output stage of the device; see Gain Staging above.
  • Scope: A dedicated tab showing live left and right waveform traces side by side.
  • Delay Effect: A built-in delay with multiple types (Stereo, Mono, Ping Pong, and Tape), feedback, depth, and optional BPM Sync.
  • Presets:
    • Factory & User Banks: Use MIDI Bank Select (CC 0) to switch between Factory (0) and User (1) presets.
    • Patch Changes: Use standard MIDI Program Change messages to load presets within the active bank.
  • Automation: The Synth supports real-time MIDI CC automation:
    • CC 7: Volume.
    • CC 10: Pan.
    • CC 74: LPF Cutoff.
    • CC 81: HPF Cutoff.

BassSynth

The BassSynth is a specialized monophonic instrument designed for classic acid basslines and powerful low-end sounds.

  • Selection: Assign a track to a specific BassSynth by selecting its name (e.g., "Noteahead BassSynth 1") in the Track Settings port list.
  • Oscillator: Choose between Triangle, Saw, and Square waveforms. The Tuning control allows for fine-tuning the pitch.
  • Sub-Oscillator: Adds a sub-octave oscillator for extra weight.
    • Sub Level: Controls the volume of the sub-oscillator.
    • Sub Octave: Choose between -1 or -2 octaves below the root.
  • Filters:
    • LPF Cutoff & Resonance: A classic 24dB resonant low-pass filter, perfect for squelchy acid sweeps.
    • HPF Cutoff: A 12dB high-pass filter for sculpting the low-end.
    • Env Mod: Controls how much the internal decay envelope affects the LPF cutoff.
  • Envelope:
    • Decay: Controls the decay time for both the amplitude and the filter cutoff modulation.
  • Acid Implementation:
    • Accent: Triggered when note velocity is above 100. It boosts the volume and increases the filter envelope's effect.
    • Slide: Enabled via the Slide control. When notes overlap or are played legato, the pitch glides smoothly between them without retriggering the envelopes.
  • Distortion: Built-in saturation for aggressive textures.
    • Drive: Controls the amount of distortion.
    • Tone: Adjusts the brightness of the distorted signal.
    • Level: Sets the output level of the distortion stage.
  • Automation: Supports real-time MIDI CC automation for Volume (CC 7), Pan (CC 10), LPF Cutoff (CC 74), and HPF Cutoff (CC 81).

DrumSynth

The DrumSynth is a specialized internal instrument for synthesizing drum sounds, featuring 11 independent voices with dedicated synthesis engines.

  • Selection: Assign a track to a specific DrumSynth by selecting its name (e.g., "Noteahead DrumSynth 1") in the Track Settings port list.
  • Voices: Features 11 voices: Kick, Snare, Closed Hi-Hat, Clap, Open Hi-Hat, Low Tom, Mid Tom, High Tom, Crash, Ride, and Reverse Crash.
  • Common Voice Controls:
    • Level & Pan: Individual volume and stereo positioning for each voice.
    • LPF & HPF Cutoff: Dedicated low-pass and high-pass filters for each voice.
    • Tune: Pitch control for the drum engine.
    • Decay & Attack: Control the amplitude envelope of the drum sound.
    • Resonance: Filter resonance for the voice's LPF.
  • Advanced Controls:
    • Kick: Click Tune, Pitch Depth, and Pitch Decay.
    • Snare: Snappy (noise level) and Tone.
    • Toms: Pitch Depth and Pitch Decay.
  • Per-Voice Insert Effects: The small FX button next to a voice opens an insert effect rack for that voice alone.
  • Automation: DrumSynth supports simplified direct MIDI CC automation for essential parameters of each voice. Automation targets include:
    • CC 7: Global Volume.
    • CC 10: Global Pan.
    • Voice Pan, LPF, and HPF: Direct CCs are assigned to each voice (e.g., Kick uses CC 14-16, Snare uses CC 17-19, etc.). The Property Service provides descriptive names for these CCs in the automation editor.

Wavetable Synth

An 8-voice wavetable synthesizer for digital and evolving timbres.

  • Oscillators: Two independent wavetable oscillators with Classic and Spectral wavetable sets, plus a noise generator.
  • Filters: Cascaded LPF and HPF with resonance.
  • Modulation: Amp and Mod envelopes and two LFOs, with the same target list as the Synth.
  • Voices: Poly and Unison modes with stereo pan spread and portamento.

Piano Synth

A physically modelled (waveguide) piano rather than a sampled one, so it stays small and responds continuously to velocity.

  • String: Brightness, Decay, Inharmonicity and Release shape the tone from a soft upright to a bright grand.
  • Global: LPF/HPF shaping, stereo pan spread, and the usual Gain/Fader/Pan output stage.

String & Voice

A vintage string and choir ensemble inspired by the Roland VP-330 and Behringer VC340.

  • Registers: Independent strings and voice (choir) sections that can be mixed freely.
  • Ensemble: A BBD-style ensemble chorus for the classic wide, shimmering movement.
  • Vocoder: A side-chain vocoder section driven by another track.

String Ensemble

A divide-down string machine in the Solina tradition. Twelve master oscillators are tapped at 16', 8' and 4' by every key, so octaves stay phase-locked and polyphony is effectively unlimited — hold as many keys as you like.

  • Bass Section (keys below B3): Contrabass 16' and Cello 8', with a Volume Bass knob to balance them against the upper section.
  • Upper Section (keys from B3 up): Horn 16', Viola 8', Trumpet 8' and Violin 4'. Any combination of registers can be on at once.
  • Envelope: Crescendo sets the attack and Sustain Length the release. Velocity sets how much playing dynamics affect the level; at zero every note plays at full level.
  • Modulation: An Ensemble chorus for the instrument's signature width, and a Phaser with Color and Rate controls.
  • Global: Gain, Fader, Pan and LPF/HPF cutoff. MIDI CC automation for Volume (CC 7) and Pan (CC 10).

Sub Mixer

Not an instrument but a grouping device: it sums other devices so a whole set is mixed and processed as one entity — for example everything except the lead synth through a single compressor.

  • Members: Choose which devices feed the Sub Mixer. Members keep their own send levels to the master send effects.
  • Processing: The Sub Mixer has its own insert effect rack plus Gain, Fader and Pan.
  • Nesting: Sub Mixers can feed other Sub Mixers.
  • Automation: Its Volume and Pan can be ridden from a track over MIDI CC, so assign a track to it as you would to an instrument.

Synchronization

Noteahead can be synchronized with external audio hosts and MIDI hardware. These options are available in Settings => MIDI => Synchronization.

  • Jack Transport Sync: (Requires **JACK** audio backend) When enabled, Noteahead acts as a JACK client and will follow the Play, Stop, and Rewind commands from a JACK transport master (like Carla or QjackCtl).
  • Jack BPM Sync: (Requires **JACK** audio backend and **Jack Transport Sync**) Noteahead will follow the BPM of the JACK host and synchronize its internal timeline to the JACK sample clock for drift-free, sample-accurate playback. The BPM display in the toolbar will update to reflect the host's tempo.
  • MIDI Transport Sync: Allows Noteahead to be started and stopped by external MIDI controllers. Support is included for standard MIDI Start/Stop messages as well as common hardware CC mappings (e.g., Arturia Keystep).

Tools & Audio

  • Audio Backend: Choose your preferred audio driver in Settings => Audio => Backend.
    • Auto: Automatically selects the best available backend.
    • ALSA / PulseAudio: Standard Linux audio backends. Device selection and buffer size can be configured directly in Noteahead.
    • JACK: High-performance low-latency backend. Device routing and buffer size are managed externally (e.g., via Carla or qpwgraph). **Required** for Jack Transport and BPM synchronization.
  • Audio Recorder & Player: Enable in Settings => Audio to capture your performance directly from your system's audio input and play back recorded files.
    • Wave View: When enabled, a waveform of the recording is shown at the bottom of the editor.
    • Playback: Use the play button next to the waveform to start or stop audio playback.
    • Navigation: Left-click on the wave view to seek both the audio playback and the main sequencer to that position. Right-click to open the folder containing the recorded file.
    • JACK mode: When the **JACK** backend is active, Noteahead provides virtual input ports (input_1/input_2) and output ports (output_1/output_2). Route your audio sources to these inputs using a patchbay.
    • Persistence: The path to the last recorded file is saved with your project, allowing for seamless workflow across sessions.
  • Playback Quality: Settings => Audio => Playback quality sets the oversampling factor used during playback: Draft (1x), Normal (2x) or High (4x). Lower saves CPU while composing; higher reduces aliasing in the internal synths. The export has its own quality setting, so you can work at 1x and still render at 4x.
  • Spread playback across CPU cores: Also in Settings => Audio, off by default. When enabled, devices are processed on several threads during playback. It needs real-time scheduling privileges; without them playback quietly stays single-threaded. Offline rendering always uses all cores.
  • Audio Renderer: Export your song to WAV or FLAC via File => Render audio....
    • Accuracy: Offline rendering ensures sample-accurate timing and full reproduction of all internal instrument behaviors, including complex automations.
    • Render Mode: Master Mix writes the whole mix; Individual Tracks writes one file per track that uses an internal device, which is how you get stems for an external DAW.
    • Audio Settings: Format (WAV or FLAC), sample rate, bit depth (16/24/32-bit PCM or 32-bit float, depending on format) and Quality (1x, 2x or 4x oversampling).
    • Export Options: Normalize audio to a target level, Trim duration to a given length, and Analyze loudness to get a LUFS, LRA and dBTP report after the render.
    • Metadata: Title, artist, album, date, genre, track number and comment are stored with the song and written into the exported file.
    • Song-Specific: All of these options are saved with the song, like the tags, so one song can never inherit another's trim length. A new song starts from FLAC, 48 kHz, 24-bit, 4x quality with loudness analysis on.
  • Delay Calculator: Quickly find millisecond values for various beat divisions based on the current BPM.
  • Note Frequency Calculator: Reference tool for sound design and tuning.
